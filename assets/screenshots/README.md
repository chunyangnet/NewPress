# UI screenshots

Captured on 2026-11-27 from the current NewPress `1.0.0-beta.1` source and the bundled Chunnel theme. The preview used an isolated environment with sample content and accounts; the UI language is Simplified Chinese. No live site data was used.

- Full-size images are lossless WebP at 1440 × 1000 pixels.
- The mobile comparison places two actual 390 × 844 captures (light and dark mode) side by side on a neutral background.
- Files ending in `-thumb.webp` are 720 × 500 previews. Each README thumbnail links to its matching full-size image.
- Image paths are relative so the same gallery can be published on GitHub and Gitee.

When refreshing screenshots, use demo data, remove image metadata, and update all four README galleries together.
