## 修复内容

1. 问答、圈子与公告样式作用域缺失，以及引用未公开核心 CSS 导致布局未生效：补充作用域并随主题携带按需样式。
2. 系统按钮的阴影、圆角、触控高度、悬停及焦点与企业主题不一致：接入 Nexora 颜色及按钮形状变量。
3. 注册介绍区对比度偏低和图片风格不一致：使用浅色说明文字与主题建筑素材。
4. 手机账号菜单受主导航规则影响：改为受视口约束的独立浮层，保留可滚动内容和触控区域。
5. 登录态页眉重复账号入口挤占窄屏空间：手机只显示账号菜单入口。
6. 快讯嵌套评论被共享布局压缩：恢复块级评论布局与正常内容宽度。
7. 访客账号页加载会员面板脚本引发初始化异常：会员资源仅登录后加载，登录成功刷新服务端页面。
8. 修正结算页重复图标、资源导航文案，补齐紧凑密度和移动输入字号。

## 复验工具

- `scripts/nexora_visual_audit.mjs`：页面矩阵、资源失败检查、截图。
- `scripts/nexora_visual_states.mjs`：真实账号状态、弹窗、菜单及脚本异常检查；截图等待动画完成。
- `internal/httpserver/nexora_visual_browser_test.go`：仅供显式启用的隔离浏览器夹具使用。

运行脚本前启动浏览器夹具与本机 Chromium 调试端口 19434。`NEXORA_VISUAL_URL` 指定夹具地址，`NEXORA_VISUAL_OUTPUT` 指定报告目录。

本轮最终浏览器复验复用了本轮较早已编译的 HTTP 测试夹具二进制，加载最新主题文件。重新编译 HTTP 包时遇到工作区其他代码 `internal/database/referrals.go` 的 `fmtReferralID` 未定义错误；该问题不属于本次主题改动。当前主题专项测试与主题检查可独立通过。
