# Nexora 企业上线指南

## 企业访问链路

首页品牌介绍 → 核心业务 → 客户案例 → 合作流程 → 企业咨询；新闻和专题用于持续传播，资料中心承接白皮书、产品手册，岗位区承接招聘。

### 1. 正式内容

在核心页面管理中发布企业介绍、解决方案、客户案例和岗位详情，再把真实的 `/pages/<slug>` 地址填入主题设置。案例支持三项，每项包括名称、成果简介、图片与详情链接。不要把未发布的草稿地址用于公开按钮。

### 2. 资料中心

在媒体库上传可公开分发的文件，将实际文件地址填入资料项；也可指向包含版本说明的正式页面。支持三项，名称和地址缺一则不显示。简介建议写明格式、版本、大小和用途。链接为普通浏览器链接，文件预览或下载行为由文件响应决定。

### 3. 合作流程

在「合作与交付流程」调整四个阶段的名称和说明，然后启用展示。默认流程文案为参考，应按实际服务交付方式修改。阶段名称为空时隐藏该阶段。

### 4. 招聘与投递

在「人才招聘」配置最多三个岗位的名称、地点/部门/类型、职责要求和详情或投递地址。岗位支持键盘和无 JavaScript 折叠展开。正式投递可连接企业招聘系统，或在岗位详情页提供招聘邮箱与申请说明；主题不在浏览器伪造申请成功，也不自行收集简历。

### 5. 业务咨询与跟进

推荐在核心功能页面建立业务咨询板块，配置提交权限、分类、私密提交和审核策略，将板块实际地址填入「首页联系合作 → 按钮地址」。客户提交、本人查看、管理员回复和状态跟进均由核心反馈功能承接。涉及联系资料的咨询应按业务需要设置私密提交。

也可填入已发布联系页或外部客户服务系统。未指定地址时，主题依次选择邮箱、电话、已启用的反馈入口；都未配置时不生成无效按钮。将「企业内容页显示咨询入口」打开后，案例、方案等正式页面底部会展示同一联系入口。

### 6. 首页与导航

客户案例、合作流程和资料中心默认关闭，启用后位于合作伙伴之后、招聘之前。无真实案例或资料时不输出空区块。默认导航将案例和资料收纳到「业务与成果」菜单，手机端仍可使用。核心自定义菜单优先，需自行添加对应入口。

可用锚点为 `/#cases`、`/#process`、`/#resources`、`/#careers`。主题 CTA 在目标模块关闭或内容为空时隐藏；联系 CTA 则寻找可用联系渠道。

## 上线验收

## 全链路界面覆盖

主题注册 22 类公共页面模板：品牌首页、新闻列表/分类/作者、文章/企业页面、系列、错误/维护、客户中心、注册找回、充值订单、产品商城、技术问答、圈子、咨询反馈、链接目录、快讯列表/详情/投稿、邮件退订与交流服务页。公告列表和详情由企业页面模板按核心页面类型分发。

这些页面共享 Nexora 页眉、页脚、搜索、配色与字体。账号菜单包含通知、私信、客户中心和退出；注册、登录与消息弹窗使用核心公开协议，系统功能样式和脚本按页面加载。管理员业务配置与后台管理继续由核心提供。

服务展示组件位于 `templates/partials/services-*.html`，资源依赖集中在 `service-assets.html`，主题适配层为 `assets/css/services.css`。模块是否可用、支付渠道、注册方式及账号权限以核心配置为准。

### 业务验收清单

1. 从首页打开实际案例、资料和岗位地址，确认内容已发布、文件可访问。
2. 用访客与普通账号分别检查咨询板块权限、提交、我的反馈和回复；用管理员完成处理。
3. 检查邮箱与电话按钮、移动菜单、岗位展开、新闻搜索和分页。
4. 关闭一个模块，确认默认导航和主题按钮同步隐藏。
5. 预览修改、保存并刷新页面，确认持久化配置正确。

自动检查：`go test ./internal/theme` 与 `go run ./cmd/themecheck -source themes/nexora`。真实业务内容和咨询板块仍需站点管理员按企业资料配置。
