# Nexora 素材清单

项目配图为 AI 生成素材，不另列来源署名。图片使用本地 WebP 文件，浏览器无需访问外部图片服务。

| 文件 | 用途 |
| --- | --- |
| `assets/images/headquarters.webp` | 第一张轮播 |
| `assets/images/headquarters-mobile.webp` | 较小尺寸备选 |
| `assets/images/about-architecture.webp` | 关于我们、第二张轮播、无封面新闻 |
| `assets/images/innovation-mountains.webp` | 第三张轮播 |
| `assets/images/innovation-banner.webp` | 创新愿景横幅 |
| `assets/images/preview.webp` | 主题预览 |
| `assets/fonts/nexora-serif.woff2` | 中文展示标题；Noto Serif SC 400 字重子集，按 OFL 重命名 |

字体继续采用 SIL Open Font License 1.1，完整许可位于 `assets/fonts/OFL.txt`，版权与字体来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。模板、样式、交互代码采用 [Apache-2.0](LICENSE)。

更换默认图片时同步更新主题预览和本清单。图形与版式由模板、CSS 和 SVG 实现，图片中不包含页面文案或可点击控件。
