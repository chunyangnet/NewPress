# Nexora · 科技企业官网

独立的 `public/v1` 企业主题。采用冷蓝建筑首屏、透明导航、宋体双行标题、关于我们、四栏优势和山峦愿景区，并延伸为完整的业务、新闻、人才、合作与页脚页面。

## 直接使用

本工作区主题位于 `themes/nexora`，可在「主题市场」启用。独立发行包也可通过 `newpress theme install <主题包绝对路径>` 安装。

需要支持 `view: public/v1` 的当前 NewPress 核心。

1. 在核心「站点设置」中设置企业名称、标语、站点图标、SEO 和备案。主题实际显示核心站点名称。
2. 在「外观与主题」中按分组配置配色、布局、标志图片、首页模块与内容顺序、首屏文案与图片、介绍、优势、业务、新闻、企业事实、合作伙伴、常见问题及联系信息。首屏、介绍与研发图片留空时使用内置素材；合作伙伴没有默认标志或演示名单。
3. 在核心「导航菜单」中分配主导航或页脚导航。未配置菜单时显示企业首页锚点和新闻中心；明确配置为空的菜单保持为空。支持三级菜单和新窗口链接。
4. 通过核心内容管理发布真实企业页面和新闻，再把按钮指向对应的 `/pages/<slug>`。首页展示最多三篇公开文章，新闻中心使用核心搜索、分类与分页。
5. 联系按钮可配置为企业联系页或业务咨询板块。未配置时依次使用企业邮箱、电话、已启用的在线留言；没有可用渠道时隐藏按钮。

主题设置覆盖品牌展示、客户案例、交付流程、资料中心、岗位招聘与内容页咨询入口，完整字段、适用范围与联动条件见 [主题设置说明](SETTINGS.md) 和 [企业上线指南](ENTERPRISE.md)。所有字段接入核心预览和保存功能。

首屏默认手动切换，可改为单屏或开启 5–15 秒自动轮播，支持按钮、圆点与方向键。自动播放提供暂停按钮，悬停、键盘焦点、页面隐藏、滚出视口与减少动态效果设置都会暂停。手机菜单支持 Escape 和焦点循环；搜索使用原生表单和可关闭对话框。没有 JavaScript 时仍可使用首屏、主导航、搜索、FAQ、新闻阅读和普通评论表单。开启评论验证时需要 JavaScript。

## 首页模块与按钮

「首页模块」包含首屏轮播、关于我们、服务优势、技术研发、核心业务、新闻动态、人才招聘、联系合作八个开关，默认全部开启。企业事实、合作伙伴、常见问题三个区块默认关闭，填写完整内容后再打开。关闭首屏时显示企业名称与标语，页面仍保留一个主标题。关闭展示模块不会关闭核心内容或系统功能。

内容顺序提供三种预设：企业介绍优先（介绍 → 事实 → 优势 → 研发 → 业务 → 新闻）、业务服务优先（业务 → 优势 → 介绍 → 事实 → 研发 → 新闻）、新闻内容优先（新闻 → 介绍 → 事实 → 优势 → 研发 → 业务）。首屏位于最前；合作伙伴、招聘、常见问题与联系区依次位于后部。切换顺序不会重新打开已关闭的模块，也不改变核心导航菜单的顺序。

企业事实最多提供四组数值或短语与说明，建议在说明中注明统计口径或时间；两项缺一则隐藏该条。合作伙伴最多六项，填写名称后才展示，图片与网站链接可选；没有图片时展示文字，没有链接时不生成空链接。常见问题最多四组，问题和回答必须同时填写，回答按纯文本保留换行，使用原生折叠控件，键盘与无 JavaScript 环境均可操作。三个新增区块都没有默认企业数据；即使开关开启，完全未填写时仍不输出区块或空标题。

默认导航随区块开关更新。按钮链接或文字留空时隐藏按钮；按钮指向已关闭或内容为空的首页区块时也会隐藏。首页锚点直接填写 `/#facts`、`/#partners`、`/#faq` 等完整站内路径，内页链接可回到首页对应位置。联系区关闭后，仍需联系入口的页眉、业务和招聘按钮改为合作按钮设置的地址；未设置地址则依次使用企业邮箱、电话或已启用的在线留言，没有可用渠道时隐藏按钮。合作按钮指向自身或不可用区块时同样使用这个回退。自定义导航仍由核心导航设置管理，修改区块开关后应检查站长自行添加的锚点。

首页由 `home.html` 编排，各区块位于 `templates/partials/home-*.html`，共享按钮规则位于 `home-actions.html`。这些文件放在同一层，以兼容核心模板加载器。首页的 `data-home-section` 标记同时供滚动定位和交互验收使用。

## 边界

- 主题只包含公共展示模板、样式、图片、字体和浏览器交互；没有管理模板、数据库、密钥或新增后端路由。
- 品牌身份、正文、发布状态、菜单、媒体、评论、账号、支付和模块开关归核心所有。
- 账号、注册找回、结算、商城、反馈、问答、圈子、快讯、导航目录、公告与邮件退订均提供 Nexora 页面，复用核心公开交互协议和按需资源。前台配色不影响后台。
- 未声明 `home-layout/v1`；企业首页用自己的展示设置组织内容，不调用 Chunnel 首页组件或布局编辑器。
- 评论使用核心原生提交协议；独立 `nexora-verification` 适配器只负责验证 UI，验证凭据的签发、消费、风控与权限仍由核心执行。站点未开启验证时不加载这个脚本。
- 主题设置中的介绍和业务描述是展示文案；正式长文和企业资料可通过核心页面管理。默认文案是可替换的参考内容。

## 构建、检查、打包

在本工作区根目录运行：

```powershell
npm run build:theme -- --source themes/nexora
npm run build:theme -- --source themes/nexora --check
go run ./cmd/themecheck -source themes/nexora
go test ./internal/theme
```

运行主题只需要已构建的静态资源，无需安装前端构建工具。

修改源文件后重新构建并重启开发实例。主题资源路径带内容摘要；运行期间直接修改文件会使原版本资源地址失效。

字体为独立授权的本地宋体子集，约 67 KiB；没有加载 Chunnel/B2 字体。默认标题字形包含在子集中，未收录的新字由系统宋体回退。图片为 WebP，首屏约 168 KiB。素材清单与许可见 [素材说明](ASSETS.md) 和 [第三方许可](THIRD_PARTY_NOTICES.md)。

## 界面与交互

首页导航按当前区块滚动高亮；内页按路径与查询条件选择菜单，多级菜单同步标识所属分组。页眉滚动后切换为实色，手机菜单支持焦点循环、Escape、背景隔离及断点恢复。分类、分页、轮播和目录使用独立的选中态，键盘焦点保持可见。

新闻、分类、标签和作者页保留各自浏览上下文。关键词与分类可以分别清除，分页继续沿用筛选。作者页依赖核心将 `SearchQuery`、`CategorySlug` 和公开分类投影到 `public/v1`；本地配套核心已补齐。专题与系列新增独立列表和章节页，文章展示系列上下篇。正文提供阅读目录、阅读时长和复制链接；评论支持回复、取消及校验失败后的内容恢复，登录用户使用账号身份。

样式按基础、导航、首页、卡片、搜索、阅读、评论与响应式拆分；浏览器源码位于仓库级 `frontend/themes/nexora/`，入口由 `frontend/entries.json` 管理。构建后仍只加载一个主样式和一个主脚本，评论验证按需加载。在仓库中修改模块后运行主题构建或 `npm run build:frontend`；仅持有安装包时需取得对应仓库源码进行开发。

- 浏览器覆盖 320、390、768、1254、1440px：默认配置 10 类页面 50 组，定制配置 6 类页面 30 组，无横向溢出、破图和未捕获脚本异常。默认配置资源请求正常，404 页面返回预期状态。

- 复测大标志与长企业名称的 320–768px 布局；修复页眉操作区和页脚横向溢出，以及实体固定页眉关闭手机菜单后意外跳回顶部。保留已有菜单、搜索筛选、评论草稿、轮播键盘和无 JavaScript 功能回归。

本轮测试使用临时主题安装和内存内容。源码和本地主题副本已同步；已发布的签名目录与发行包保持原版本。
