# DocsHub 2.0.1 功能对标与验收

验收日期：2026-11-23。对标本次工作区的默认主题 Chunnel 0.48.1，核心版本 `0.1.0-dev`。主题采用 `public/v1` 与 `home-layout/v1`，面向产品文档、开发教程、技术知识库与课程站点。

## 页面覆盖

默认主题的 24 个公开模板映射均有 DocsHub 实现。没有依靠默认主题页面回退来补全界面。

| 映射 | DocsHub 页面与闭环 |
|---|---|
| `home` | 经典文档首页、可编排首页、学习入口、文档流、最近阅读与清除、登录与签到 |
| `single` | 文档阅读、目录、代码复制、收藏、点赞、分享、打印、专注阅读、评论与回复、资源解锁 |
| `page` | 独立内容页；公告目录、搜索、筛选、详情及上下篇 |
| `explore` | 搜索、分类、排序、卡片/列表、清除筛选、分页、无结果恢复入口 |
| `archive` | 分类/标签归档、文档卡片、分页与空状态 |
| `author` | 作者资料、文章目录、关注、认证与互动入口 |
| `series` | 学习系列目录、系列详情、阅读顺序与课程文章入口 |
| `404` | 缺失内容提示与返回首页、文档中心入口 |
| `maintenance` | 维护状态说明与站点导航 |
| `account` | 收藏夹、资料、互动、关注、私信、通知偏好、钱包、成长与会员、身份认证、本机记录导入 |
| `account-access` | 登录、注册、邮箱验证码、找回密码及服务未开放状态 |
| `billing` | 购买方案、付款核对、订单、状态同步与取消入口 |
| `shop` | 商品目录、分类/搜索/排序/筛选、详情与购买方案、结算、付款、订单交付、评价与售后入口 |
| `questions` | 技术问答目录、搜索、状态筛选、提问、详情、编辑、回答、补充与采纳 |
| `circles` | 学习小组目录、加入/申请、话题、回应、编辑、举报与成员权限 |
| `community` | 协作入口页，连接问答、小组、反馈与文档 |
| `feedback` | 反馈目录、看板、提交、投票、回复、状态、历史与私密反馈权限 |
| `links` | 开发者导航目录、分类、搜索、多种显示方式与外链 |
| `flash` | 技术快讯目录、筛选与分页 |
| `flash-single` | 快讯详情、导航、评论及正确的快讯评论提交路由 |
| `flash-submit` | 草稿、提交审核、已有稿件、状态与编辑权限 |
| `notification-unsubscribe` | 有效令牌确认、实际退订提交、保存结果及无效令牌状态 |

所有页面共用 DocsHub 侧栏、顶栏、字体、蓝色强调色、深浅色与移动导航。默认学习入口、文案、推荐阅读和协作入口按文档站定位组织；后台管理、宣传截图、审核与业务规则仍由核心提供。

## 可编排首页与设置

默认保留经典首页。开启 `use_home_layout` 后，支持布局目录中的全部 25 个模块：

| 默认区域 | 模块 |
|---|---|
| 顶部，8 个 | `hero`、`notice`、`channels`、`categories`、`reading_guide`、`carousel`、`search_banner`、`custom` |
| 主栏，4 个 | `feed`、`series`、`spotlight`、`community` |
| 侧栏，13 个 | `focus_list`、`topic_banner`、`entry_cards`、`image_grid`、`notice_list`、`welcome`、`checkin`、`updated`、`recent`、`authors`、`tags`、`stats`、`subscribe` |

模块可排序、跨区域编排、选择桌面/手机可见性；支持自定义 HTML、间距与侧栏宽度。缺少内容、未开放服务或关闭相应模块时，核心按实际状态决定可用性。轮播支持前后切换、暂停、触摸与减少动态效果；背景搜索支持渐变、图片与视频设置。

文档流保留搜索、分类、排序、视图与分页状态。切换视图后返回 `#latest`；列表为单列，卡片按屏幕宽度排列。首页账户区从会话接口读取真实姓名、成长和签到状态，避免公共首页缓存混入用户身份。切换账户、退出或迟到的网络响应不会覆盖另一用户的显示。

提供 **22 组、236 个设置**，自定义内容仅使用 home_custom_blocks，不保留旧单例 HTML 字段。设置保存、验证、后台表单、预览及布局开关均经过检查；字段只出现一次。完整清单见 [SETTINGS.md](SETTINGS.md)。

## 权限与异常状态

| 场景 | 处理与验证 |
|---|---|
| 游客与登录用户 | 35 条服务路由分别按两种身份访问，校验正确模板与共享资源；受保护操作使用登录入口与核心授权 |
| 模块关闭 | 默认导航、首页辅助入口与相应服务入口跟随核心模块开关 |
| 问答隐私 | 隐藏回答和举报不进入公开展示契约；编辑原文只提供给有权限的用户；投影切片独立复制 |
| 私密反馈 | 其他用户不能读取，公开目录不泄露记录 |
| 商品交付 | 实际钱包支付、重复付款请求与购买者读取；另一用户读取同一订单被拒绝 |
| 文章资源 | 视频与资源资产由核心注入；解锁后读取，游客仍看不到受保护内容；未提前创建视频 iframe |
| 通知 | 偏好保存后重新读取；退订使用真实令牌完成确认、提交和持久化 |
| 浏览器偏好 | 本机阅读历史可清除；隐私授权拒绝、允许、重载与重新打开均有效 |
| 手机键盘操作 | 抽屉打开后背景不可交互，Tab 留在抽屉，Escape 关闭并返回触发按钮；底栏按页面类型标识当前位置 |

## 交付要求

DocsHub 2.0.1 需要核心提供 Questions、Flash、AnnouncementPage、ShopProductKey、ShopDescriptionHTML 展示字段、256 项设置容量及布局编辑器开关；不能仅凭主题版本判断旧核心具备这些能力。安装前使用目标核心的 `cmd/themecheck` 加载本包并检查实际页面，缺少字段或设置容量支持时先更新核心。

业务闭环由主题交互与核心接口共同实现。邮箱、OAuth、支付、会员、认证和审核是否开放，取决于站点配置及权限；主题提供对应入口、状态与恢复路径。设备截图工具使用核心组件；本次未穷举所有浏览器、支付渠道、商品组合或外部邮件供应商。

产物为本地 `docshub-2.0.1.zip`，包含完整源码、生成资源、设置、文档及许可；不包含演示数据。2.0.1 尚未发布到签名市场目录。
